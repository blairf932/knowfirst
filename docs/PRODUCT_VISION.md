# Product vision

AI-Frontier 帮助开发者在学习、选型和开发之前，理解技术路线、检查已有方案、追溯证据及变化，降低重复开发的成本。

核心资产是 **Technology Intelligence + Knowledge Graph + Evidence + Time + Personal Relevance**。每一次来源抓取增加可追溯观测，每一次事实变化保留历史，每一次决策说明依据与缺口。

v0.1 只覆盖 AI Agent 生态的 17 个主题与 7 个项目，不以收录数量冒充覆盖整个 AI 世界。入口支持中英文概念和构建需求，输出 Frontier Card、比较和 Build or Buy 分析。

事实与分析必须区分：仓库元数据是来源事实；README 提到某能力是对文档声明的事实；是否适合具体用户、是否成熟、是否应该集成仍然需要分析和验证。

成功指标（尚未开始采集商业统计）：用户避免重复开发的次数；进入集成验证的比例；决策证据覆盖率；事实验证时延；每张卡片成本；历史事实可重建率。页面浏览量和 Stars 数量不能独立代表成功。

边界：不做无证据 AI 排名、不抄录整篇外部内容、不保证覆盖全部产品、不把模型答案伪装成情报数据库。
