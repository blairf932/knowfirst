# 未来方向

这份文档记的是这个项目接下来想往哪走。先说清楚：**这里没有承诺，没有排期，随时会改。** 它只回答一个问题——有人问"这项目要干嘛"，照着说，而不是现编。

## 一条底线

证据纪律不能丢：事实和分析分开，没证据就是 UNKNOWN，历史只追加不覆盖。

所以凡是会让软件"学会撒谎"的方向都不碰——用推断填空白、拿一个数据点编趋势、把模型输出当事实。方向可以换，这条不换。

## 最想做的：证据时间线

数据模型已经是 append-only 的时间性事实（`valid_from` / `valid_until`），缺的只是一层界面。

把一个技术的能力怎么随时间变，做成能回放的时间轴。有人问"Mem0 现在支不支持 OpenClaw"，不给他一个拍脑袋的答案，给他看演变过程：什么时间、哪个来源、说过什么、后来有没有删掉。这是现在没人做的事，因为别人的数据模型只存最新值，根本不支持回溯。

成本小，价值独一份。这是下一件想动手的事。

## 有点意思但先不碰

- **给 agent 当可信事实源**：价值最大，但会把项目从"研究工具"变成"基础设施"，复杂度不是一个量级。先看着。
- **记录自己对技术的判断**：跟这个项目的脾气很合，但产品形态没想清楚。搁着。

## 不做的事

- **让模型自动做分析、排名**。一开这个口子，前面攒的所有洁癖全没了。
- **把收录扩到全网**。一扩大，就再也做不到"每条都能人工复核"。
- **加聊天机器人**。会变成第 N 个聊天工具，差异化就没了。

## 排期

没有。个人项目，哪天想动工了，再看这条文档决定先做哪一条。
