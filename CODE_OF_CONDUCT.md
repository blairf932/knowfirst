# Code of Conduct

## The short version

Be straightforward with people. Argue about code, data and evidence, not about who is right.

## What that means here

This project is built on one idea: separate what you know from what you assume. It applies to
people too.

Accepted:

- Disagreeing hard about design, evidence quality, or whether a claim is supported.
- Saying "this part is unverified" about your own work.
- Asking a question that sounds basic. Everyone started somewhere.

Not accepted:

- Personal attacks, harassment, or sustained disruption in issues and pull requests.
- Publishing someone's private information without their consent.
- Presenting unverified work as verified to win an argument. That is the one thing this codebase
  exists to prevent.

## Scope

This applies to issues, pull requests, discussions, and any space where someone is representing
this project.

## Reporting

If something happens, contact the maintainer privately through the GitHub profile at
<https://github.com/blairf932>. Reports are read and handled privately. If a report involves the
maintainer, say so — that is a legitimate thing to raise.

Response is best-effort. This is a small project with no staff.
